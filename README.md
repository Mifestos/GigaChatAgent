# GigaChatAgent

**GigaChatAgent** — это автономный AI-агент для безопасного и бюджетируемого анализа данных. 
Агент принимает на вход CSV-файл и текстовую бизнес-задачу, генерирует Python-код с помощью LLM (GigaChat), проверяет его на безопасность, выполняет в изолированной среде и способен самостоятельно исправлять возникающие ошибки.

## Ценность проекта (Value Proposition)

При построении AI-агентов, которые выполняют код, возникают три главные проблемы: безопасность, неконтролируемые расходы и непредсказуемое качество. Этот проект решает их на архитектурном уровне:

1. **Безопасность (Isolation):** Сгенерированный нейросетью код никогда не выполняется на хост-машине. Он изолирован в облачной песочнице (E2B), что исключает риск удаления файлов или несанкционированного доступа к сети.
2. **Контроль затрат (Budgeting):** Внедрена система Guardrails, которая жестко ограничивает количество итераций и потраченных токенов. Агент не может уйти в бесконечный цикл и «сжечь» бюджет API.
3. **Измеримость (Evaluation):** Качество работы агента проверяется не субъективно, а с помощью Eval Harness на Golden Dataset. В репозитории зафиксированы объективные метрики (Pass@1).

## Результаты оценки (Evaluation Metrics)

Проект протестирован на Golden Dataset (5 задач по предсказанию оттока клиентов Telco Customer Churn):
* **Pass@1 (Точность с первого раза):** 100% (5 из 5 задач).
* **Средний расход токенов на задачу:** ~330 токенов.
* **Среднее время выполнения:** < 10 секунд.

## Технологический стек

| Компонент | Технология | Назначение |
| :--- | :--- | :--- |
| **Оркестрация** | LangGraph | Управление состоянием графа, логика self-correction |
| **LLM** | GigaChat (Sber) | Генерация Python-кода |
| **Среда выполнения** | E2B Code Interpreter | Безопасный запуск кода в изолированном контейнере |
| **Валидация** | AST + RegEx | Блокировка опасных конструкций (os.system, subprocess) |
| **CLI** | Typer + Rich | Удобный интерфейс командной строки с подсветкой |
| **Данные** | Pandas | Обработка табличных данных |

## Архитектура

Проект использует современный `src`-layout и разделен на слои, что позволяет легко заменять компоненты (например, сменить LLM или песочницу) без переписывания логики.

* `llm/` — клиент GigaChat и промпт-инжиниринг.
* `tools/` — статический анализатор кода (Validator) и исполнитель в песочнице (Sandbox).
* `guardrails/` — система контроля бюджетов (BudgetTracker).
* `graph/` — граф состояний LangGraph (узлы генерации и выполнения).
* `evaluation/` — испытательный стенд для замера качества.

## Быстрый старт

### 1. Установка зависимостей
```bash
git clone https://github.com/Mifestos/GigaChatAgent.git
cd GigaChatAgent
python -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install -e .
```
### 2. Настройка окружения
Создайте файл .env в корне проекта и добавьте ваши API-ключи:

```env
GIGACHAT_CREDENTIALS=ваш_ключ_авторизации_сбера
E2B_API_KEY=ваш_ключ_от_e2b.dev
```
### 3. Запуск агента
Используйте CLI для анализа ваших данных:

```bash
python -m gigachat_agent.cli -f data/raw/data.csv -q "Найди средний срок контракта для ушедших клиентов"
```
### 4. Запуск тестов и оценки
```bash
# Запуск юнит-тестов
pytest tests/ -v

# Запуск оценки качества на Golden Dataset
python -m gigachat_agent.evaluation.harness
```

## Сценарии использования (Use Cases)

### 1. E-commerce и Retail
*   **Задача:** "Посчитай общую выручку по каждой категории товаров и отсортируй по убыванию."
*   **Задача:** "Найди топ-5 самых продаваемых товаров по количеству штук."

### 2. HR-аналитика
*   **Задача:** "Выведи среднюю зарплату по каждому отделу и общее количество сотрудников в каждом отделе."
*   **Задача:** "Найди корреляцию между стажем работы (YearsAtCompany) и увольнением (Attrition)."

### 3. Банки и Финансы
*   **Задача:** "Посчитай процент клиентов, которые ушли (Churn='Yes'), в зависимости от типа контракта."
